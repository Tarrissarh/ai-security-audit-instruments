# Интеграционные испытания

Эта директория содержит инструменты и инструкции для проверки комплекта в OpenCode, DeepSeek Harness, Claude Code, Codex и Cursor. Локальные Python-тесты **не запускают** AI-клиенты и не подтверждают E2E.

## Содержание

- [Матрица совместимости](MATRIX.md) — подтверждённые уровни тестирования и ограничения.
- [Подготовка тестовой среды](runtime/README.md) — развертывание безопасного искусственного проекта.
- [Клиентские испытания и свидетельства](runtime/CLIENT-TESTING.md) — запуск, проверка журналов, оценка качества.
- [Шаблон свидетельств](evidence-template.json) — формат данных операторских наблюдений.
- [Локальный отчёт](offline-results.json) — машинные результаты тестов установщика, не реального AI-клиента.

## Правила

- Запускай AI-клиент только по отдельному разрешению человека на искусственном проекте.
- Не исполняй исследуемый код; ограничивай доступ к сети/файлам средствами клиента и, по необходимости, OS-изоляцией.
- Не передавай `quality/gold/` и эталонные предсказания модели до окончания аудита.
- Не объявляй `CLIENT_PASS` по одному текстовому ответу модели, коду выхода CLI или SHA-256 журнала.
- Не запускай `ai-tool-generator` автоматически, даже если обнаружена отсутствующая зависимость.
