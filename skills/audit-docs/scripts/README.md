# Вспомогательная запись отчётов

Это **доверенный вспомогательный код самого `audit-docs`**, а не содержимое исследуемого инструмента. Не используй скрипт для исполнения или изменения исходников проверяемого проекта.

## Назначение

`safe_writer.py` публикует предварительно подготовленные Markdown-файлы из отдельного каталога в явно выбранный каталог результата. Поддерживает только:

```text
README.md
docs/**/*.md
translations/**/*.md
```

**Не удаляет** старые файлы, в том числе `RU.md` и `TRANSLATE.md`, не устанавливает зависимости и не обращается к сети. Для миграции старых переводов требуется отдельная проверка и разрешение по правилам `references/safe-file-operations.md`.

## Условия использования

1. Сначала выполнить аудит без запуска исследуемого кода.
2. Подготовить итоговые Markdown в отдельном staging-каталоге и проверить содержимое/секреты.
3. Согласовать папку записи. Рекомендуемый путь — `<target>/audit`, а не корневой каталог чужого проекта.
4. Если доступен Python и пользователь разрешил создание документации, при необходимости **вручную**, без автоматической установки зависимостей, установить `markdown-it-py` из `requirements.txt`.
5. Выполнить публикацию:

```bash
python /path/to/audit-docs/scripts/safe_writer.py --staging /path/to/prepared-report --output /path/to/target/audit
```

При повторной публикации в тот же каталог после проверки содержимого:

```bash
python /path/to/audit-docs/scripts/safe_writer.py --staging /path/to/prepared-report --output /path/to/target/audit --overwrite
```

`--overwrite` разрешает замену только соответствующих Markdown-файлов с проверенными побайтовыми резервными копиями в `.audit-backups/`. Без этого флага существующие документы не меняются.

Скрипт проверяет локальные ссылки, запрещает символьные ссылки внутри путей записи, пишет через соседний временный файл, проверяет SHA-256 и при стандартной ошибке пытается откатить записанные файлы. Не защищает от одновременного враждебного изменения файловой системы и **не гарантирует восстановление после выключения питания или принудительного завершения процесса**. Наличие отдельного менеджера этапов `workflow_state.py` не делает публикацию crash-safe транзакцией; такие гарантии здесь не заявляются.

Ссылки на внешние URL локально не проверяются. Ссылки вида `/root/path` считаются непроверяемыми и запрещены скриптом публикации отчёта.
