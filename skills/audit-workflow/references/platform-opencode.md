# Адаптер: OpenCode

- Достоверный проектный источник: `.opencode/skills/<name>/SKILL.md`; также обнаруживаются `.agents/skills` и `.claude/skills`, глобальные пути из [официальных docs](https://opencode.ai/docs/skills).
- Хост отображает каталог Skills и штатный `skill` tool с аргументом `id`; убедись, что текущему агенту разрешено `skill` для требуемых ID. При отсутствии доступа к tool используй чтение установленного `SKILL.md` только как fallback.
- `name` во frontmatter — подпись, а ID определяется путём; поддерживай совпадение для переносимости. Избегай двух разных кандидатов с одним ID.
- Поле `disable-model-invocation: true` скрывает Skill от автоматического модельного каталога, но явная загрузка может оставаться доступной; **внутренний запрет на генерацию без просьбы человека обязателен**.
- При вызове `audit-docs` не считай фразу «Используй скилл» подтверждением; подтверждение — успешный tool result или применение реально прочитанных инструкций.
- Не создавай `opencode.json` или не меняй permissions автоматически.
