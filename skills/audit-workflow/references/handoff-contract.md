# Контракт передачи результатов между этапами

Не требуется отдельный агентный API или специальный JSON runtime. Достаточно сохранить структуру данных в текущем контексте и затем создать человекочитаемый отчёт. Не переносить исходный код в сети для межскиллового взаимодействия.

## Обязательные поля

- `run_id`: если доступен фактический идентификатор запуска; иначе дата + локальная пометка без догадок.
- `target`: канонический путь, тип, версия/commit если известна, хеш **только если посчитан**.
- `host_profile`: хост, пути, доступные capabilities, ограничения.
- `audit`: findings[] (`id`,`severity`,`file`,`line`,`evidence`,`confidence`,`fix`,`verification`), `checked_files[]`, `unverified[]`, `security_scope`, `dependencies[]`.
- `improve`: proposals[] с эффекта/риском/приоритетом, либо статус причины пропуска.
- `modernize`: proposals[] с датой, официальным источником, версиями и статусом проверки, либо причина пропуска.
- `docs`: список реально созданных путей, статус записи/резервирования/миграции, результат проверки ссылок.
- `stages`: по одному статусу и способу исполнения на этап.

## Правила

1. `SKILL_CALL` фиксируй только при реальном штатном вызове; текст инструкции недостаточен.
2. `READ_INSTRUCTIONS` фиксируй, когда локальный `SKILL.md` реально прочитан и применён в текущем контексте.
3. Предыдущая стадия не вызывает следующую при запуске через `audit-workflow`; вызовы контролируются оркестратором для предотвращения циклов.
4. Отсутствие веб-доступа не запрещает локальный аудит, но `modernize` должен пометить проверку текущих версий `UNVERIFIED`.
5. Прежде чем формировать вывод, убедись, что `docs/workflow-status.md` отражает реально выполненные шаги, а не план.

## Пример таблицы в `docs/workflow-status.md`

| Этап      | Статус   | Метод             | Доказательство/выход | Ограничения |
| --------- | -------- | ----------------- | -------------------- | ----------- |
| PREFLIGHT | COMPLETE | LOCAL_ANALYSIS    | ...                  | ...         |
| AUDIT     | COMPLETE | READ_INSTRUCTIONS | ...                  | ...         |
| IMPROVE   | COMPLETE | READ_INSTRUCTIONS | ...                  | ...         |
| MODERNIZE | SKIPPED  | NOT_RUN           | ...                  | нет сети    |
| DOCS      | COMPLETE | READ_INSTRUCTIONS | README.md, docs/...  | ...         |
| VALIDATE  | COMPLETE | LOCAL_ANALYSIS    | ссылки подтверждены  | ...         |
