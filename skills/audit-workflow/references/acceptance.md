# Проверка завершения аудита (без запуска исследуемого кода)

## Обязательные условия

- `AUDIT`: профильный анализ на реальных исходниках или откровенно помеченный `BLOCKED`; список файлов и ограничений.
- `DOCS`: созданный `README.md` с выводами и ссылками; при достаточно большом отчёте — связанные `docs/*.md`; переводы в `translations/` только из фактических оригиналов.
- `VALIDATE`: ссылки внутри созданных Markdown действительны, пути не выходят за корневой каталог, файлы не пусты, обязательные разделы есть.
- Оригиналы исполняемых инструментов/конфигураций неизменны; если заменили старую документацию — есть проверяемая резервная копия.
- Реестр внешних инструментов отличает подтверждённо отсутствующие зависимости от недоступных для поиска.
- `ai-tool-generator` не исполнялся без явного отдельного поручения пользователя.
- Для каждого `CVE`/версии библиотеки обозначены источники и фактическая дата либо `UNVERIFIED`.
- `docs/workflow-status.md` не должен утверждать о вызовах Skills, которых не было.

## Итог

- `COMPLETE`: все обязательные результаты подтверждены и доступна документация.
- `PARTIAL`: часть этапов/отчётов недоступна, но фактическая аналитика сохранена.
- `BLOCKED`: нет данных для аудита/невозможно прочитать исходники.
- `FAILED`: собственные операции создания документов завершились ошибкой, требующей исправления.

Никакое статическое соответствие формату SKILL.md не является доказательством совместимости в конкретном запущенном клиенте. Для подтверждения нужны эксплуатационные тесты из `TESTING.md`.
