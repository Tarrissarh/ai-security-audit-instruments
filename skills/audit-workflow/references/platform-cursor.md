# Адаптер: Cursor

- Проектный каталог `.cursor/skills/<name>/SKILL.md` или `.agents/skills/<name>/SKILL.md`. Cursor также может читать совместимые каталоги `.claude/skills` / `.codex/skills`, поэтому избегай дубликатов ID.
- Ручное использование — `/` в Agent чате; автоматическое зависит от выбора моделью и текущих прав. Не полагайся на невидимый API делегирования.
- Глобальный `~/.cursor/skills` не гарантирует доступность в Cloud Agents/удалённых средах до синхронизации; `~/.agents/skills` не копируется в облачную среду автоматически. Для cloud-first сценария используй проектные Skills или официальную синхронизацию.
- Генерация и операции изменения требуют пользовательского запроса, даже если скилл можно выбрать из UI. Проверяй разрешения на запись.
- Native Agents/Commands/Hooks отличаются от Claude/OpenCode: генерируй их только после чтения Cursor-specific требований.

Источник: https://cursor.com/docs/skills
