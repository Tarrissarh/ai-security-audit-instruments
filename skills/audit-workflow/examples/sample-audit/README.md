## Навигация

- Полные подробности — `docs/security.md`, `docs/recommendations.md`.
- Перевод оригинала — `translations/SKILL.md`.

## Как это связано с рабочим процессом

Реальный аудит выполняет `audit-workflow` → профильный аудитор → `audit-docs`,
который и формирует такие файлы. Этот пример — только образец для онбординга
и ручной проверки структуры отчёта.
