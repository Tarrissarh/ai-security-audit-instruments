# Матрица типов AI-инструментов

| Тип     | Когда использовать                                     | Минимальные компоненты                                           | Что не делать                                                             |
| ------- | ------------------------------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Skill   | Повторяемый промпт и справочники для модели            | `SKILL.md`, при необходимости `references/`                      | Не создавать бесполезные MCP/API                                          |
| Agent   | Отдельная роль с tool permissions/автономным workflow  | Определение роли, лимиты и выходы                                | Не давать неограниченные права                                            |
| Command | Явный пользовательский запуск повторяемого действия    | Определение команды, аргументы                                   | Не смешивать shell и произвольный ввод                                    |
| MCP     | Нужно предоставить Tool/Resource/Prompt через протокол | Сервер, схемы, transport, ошибки, документация                   | Не объявлять устаревшую версию актуальной                                 |
| LSP     | Редактору нужен языковой сервис по LSP                 | Инициализация, capabilities, message handlers                    | Не добавлять возможности без реализации                                   |
| Hook    | Нужен обработчик поддерживаемого события               | Схема событий, handler, безопасность                             | Не включать на автоматический запуск в процессе создания                  |
| Rules   | Нужны постоянные инструкции/поведение агента           | Файл правил с `description` и триггерами (`globs`/`alwaysApply`) | Не задавать `always` без обоснования; не переопределять системные правила |

## Дополнительные требования

**Skills.** Для Agent Skills обязательны YAML frontmatter (`name`, `description`) и инструкции в `SKILL.md`. `references/`, `scripts/`, `assets/` — по назначению; Progressive Disclosure. Документация: https://agentskills.io/specification. На платформе, имеющей отличия, проверь их отдельно.

**Agents.** Не путай файловый subagent IDE и автономный оркестратор. Зафиксируй права, границы, политику завершения, способ получения недоверенных материалов, ограничения стоимости и повторов.

**Commands.** Не считай одинаковыми форматы команд Claude, Codex, Cursor. Укажи платформу и проверенный формат; для shell-подобного исполнения различай argv-массивы и строки, запрещай произвольную командную интерполяцию.

**MCP.** На момент аудита источников 2026-11-12 официальная ревизия 2026-07-28 меняла модель сессий/инициализации по сравнению с ранними версиями. **Всегда перепроверяй действующий стабильный протокол, SDK и транспорты на дату нового запроса**, используй версионированные документы. Старт сервера, сетевые токены и привязка к клиенту требуют отдельного решения пользователя. Источник: https://modelcontextprotocol.io/specification.

**LSP.** Зафиксируй платформу/язык/runtime, capabilities, обмен сообщениями и безопасную обработку workspace. Не выдавай скелет за полноценный языковой сервер.

**Hooks.** Для каждого hook укажи события, фильтры, условия вызова и последствия; по умолчанию генерация не активирует обработчики.

**Rules.** Укажи клиент и формат (`AGENTS.md`, `.cursor/rules/*.mdc`, `.windsurf/rules/*.md`, `.github/copilot-instructions.md`). Дай `description`, область действия через `globs`/`alwaysApply`, избегай автоинструкций с побочными эффектами и не переопределяй системные правила; не включай правило в `always` без необходимости.
