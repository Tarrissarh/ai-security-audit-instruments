# Открытые задачи и возможные улучшения

Здесь перечислены **только актуальные незавершённые задачи**. Завершённые изменения и версии находятся в [CHANGELOG.md](CHANGELOG.md).

## P0 — реальные испытания в AI-клиентах

- Получить доступ к настроенным OpenCode, DeepSeek Harness, Claude Code, Codex и Cursor либо их подлинным журналам.
- Проверить обнаружение Skills, загрузку справочников, делегирование и полный `AUDIT → IMPROVE → MODERNIZE → DOCS → VALIDATE`.
- Проверить ограничения записи, сети, ручное разрешение генерации и отсутствие выполнения проверяемого кода.
- Сохранить независимые доказательства и метрики precision/recall/F1 на тестовых заданиях. Не засчитывать эталонные ответы за реальные.

## P1 — подтвердить переносимость Windows/Linux

- Запустить CI на реальных Windows и Linux runner.
- Проверить особенности NTFS: ACL, junctions/reparse points, блокировки файлов, замену и откат.
- Проверить создание отчетов на обеих ОС с Unicode, UTF-8 BOM и CRLF.

## P2 — улучшения с подтверждённой пользой

- По результатам клиентского E2E исправить только воспроизводимые несовместимости загрузки или вызовов Skills.
- Добавить регрессионные кейсы для новых подтверждённых проблем и верифицировать их исправление.
- При увеличении объёма инструкций переносить длинные справочники в `references/`, не ухудшая обнаружение и качество работы.

До выполнения указанных испытаний не помечать клиентскую совместимость и поведение Windows как подтверждённые. Актуальная [матрица](integration/MATRIX.md).
